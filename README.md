# 久坐提醒

计时结束后弹出对话框。点「已知晓」才开始下一段计时；不点则窗口一直停着，不计时。

对话框会浮在最前（含 Stage Manager），并弹在鼠标所在屏幕的当前桌面上，包括其他 App 的全屏桌面。

## 使用

双击 `久坐提醒.app`。首次询问间隔（默认 45 分钟），点「开始计时」。

- **已知晓**：从这一刻重新计时
- 不点：下一段计时不会开始
- 计时期间再点 Dock / App：显示剩余时间
- **结束今天**，或 Dock 图标右键退出：停止

开机自启：系统设置 → 通用 → 登录项 → 把本 App 加进去。

## 构建

```bash
./build.sh
```

源文件是 `sit-reminder.applescript`。
